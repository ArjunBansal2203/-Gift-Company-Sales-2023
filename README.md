# 🎁 Gift Company Sales Dashboard

## 📌 Introduction

Built an interactive Excel dashboard to analyze **1,000+ orders across 70 products and 100 customers**, focusing on revenue, product performance, customer behavior, occasions, seasonality, and delivery performance.

## 🛠️ Technologies

Microsoft Excel · PivotTables · PivotCharts · Slicers · Data Analysis

## ✨ Features

- Interactive Excel dashboard
- Revenue and product performance analysis
- Customer and gender-based analysis
- Occasion-based sales analysis
- Monthly and seasonal revenue trends
- Delivery performance analysis
- Interactive filters using slicers

## 🔄 Process

1. Cleaned and organized the sales data in Excel
2. Created calculated fields for revenue, revenue share, and revenue per order
3. Used PivotTables and PivotCharts to analyze products, customers, occasions, and time periods
4. Compared delivery times against a 5-day benchmark
5. Built an interactive dashboard using slicers for exploration

## 📊 Results

- **Colors generated ₹10.06L**, contributing **28.6% of total revenue**
- **Anniversary** generated ₹6.75L in revenue
- **August** was the strongest month with ₹7.37L revenue
- Revenue was almost evenly split between male and female customers
- **49.3% of orders** took more than 5 days to deliver

- Creating meaningful business KPIs from raw data
- Analyzing customer and product performance
- Turning data into clear, actionable business insights
