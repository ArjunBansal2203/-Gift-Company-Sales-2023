# 🎁 Gift Company Sales Dashboard

Built an interactive **Excel dashboard** analyzing **1,000+ orders, 70 products, and 100 customers** to understand revenue, product performance, customer behavior, occasions, and delivery performance.

### 📊 Key Insights
- 💰 **Colors generated ₹10.06L — 28.6% of total revenue**
- 🎉 **Anniversary** generated ₹6.75L, while Raksha Bandhan had higher revenue per order
- 📅 **August** was the strongest month with ₹7.37L revenue
- 🚚 **49.3% of orders** took more than 5 days to deliver

### 🛠️ Tech
**Excel · PivotTables · PivotCharts · Slicers · Data Analysis**
